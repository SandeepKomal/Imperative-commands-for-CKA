# Contributing

Thanks for improving this CKA command reference.

## Guidelines

- Keep commands practical and exam-focused.
- Prefer current `kubectl` syntax and call out version-sensitive behavior.
- Include a short explanation when a command has important selector, namespace, or dry-run behavior.
- Never commit real credentials, kubeconfigs, tokens, or private cluster data.
- Keep examples reproducible with placeholder names such as `<pod>` and `<namespace>`.

## Pull requests

Please explain:
1. What command or topic was added or corrected.
2. Why it is useful for CKA preparation or Kubernetes operations.
3. Any Kubernetes version considerations.
